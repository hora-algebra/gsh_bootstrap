# F20 有限符号ブロック分解（ルート iii）: 遅延定理による一般的な閉塞（2026-07-25、負の結果）

対象は `HeightOneForGroup F_20`。`FULL-ALPH-RED-01`（`PROVED`）により、これは**全 20 元
アルファベット** `Σ = F_20` 上の恒等ファイバー

    T = mu^{-1}(e) = { w : Σ eps ≡ 0 (mod 4) かつ beta(w) ≡ 0 (mod 5) }

の一般化スター高さ ≤ 1 と同値である。`PROOF_OBLIGATIONS.md` N-F20-001 のルート (iii) は
「§5.9（`weis_l2_family.py`）の鍵 1 を移植する」ものだった。すなわち**無限符号を有限
接頭符号に置き換え**、有限性から星無し性を自明にし、必要な段階付きカウントを
「トークン数と文字数の厳密な整数恒等式」から復元する。

結果は**符号ごとの失敗ではなく、あらゆる有限符号についての定理**である。しかも
`F_20` 固有ではなく、**任意の有限群の全要素アルファベット**に対して成り立つ。

機械検証: `scripts/f20_block_decomposition.py`（約 20 秒、全数判定、標本抽出なし）。
実行マニフェスト: `data/experiments/f20_block_decomposition.md`。

## 1. 何が「ブロック分解」か（scheme の固定）

有限集合 `X ⊆ Σ⁺` を符号とする。§5.9 の形は「貪欲パースと有界な尾部」であった:
ある有限集合 `F` について `Σ* = X* F`。同値な言い換えは

> **有界遅延**: ある `D` が存在して、長さ `D` 以上の任意の語は長さ `D` 以下の
> `X`-接頭辞を持つ。

`X` が接頭符号なら貪欲パースは一意で、`w = x_1 ... x_n f` と分解される。このとき

    mu(w) = mu(x_1) ... mu(x_n) mu(f)

であり、トークン `x` はその像 `mu(x) ∈ F_20` を通してしか効かない。したがって
**トークン語は再び「群元を文字とする語」であり、§5.12 の座標公式がそのまま一段上で
成り立つ**（スクリプト §2 で、`Σ²` と `Σ³` を符号として長さ ≤ 4 の全語 336,842 件で
機械検証）。すなわち **ブロック分解は「アルファベットを `mu(X)` に取り替える」操作
以外の何もしない**。この観察が以下すべての土台である。

## 2. 主定理（遅延定理）

> **定理 1.** `G` を有限群、`Σ = G` を全要素アルファベット（したがって単位元 `e` は
> 文字である）とする。`X ⊆ Σ⁺` が有限かつ有界遅延なら `mu(X) = G`。

**証明.** `z ∈ G` を任意に取る。語 `z e^D`（文字 `z` のあとに恒等文字 `e` を `D` 個）は
長さ `D` 以上なので `X` に属する接頭辞を持つ。ところが `z e^D` の空でない接頭辞は
`z e^j`（`0 ≤ j ≤ D`）だけで、その像はすべて `z` である。よって `z ∈ mu(X)`。∎

ファイバーだけをパースすれば十分だという逃げ道も塞がっている（scheme が先に場合分けを
して `T` の語だけ扱う、という設計は自然なので、ここは重要である）:

> **定理 1'.** 同じ設定で、`T ⊆ X* F` を仮定するだけで `mu(X) ⊇ G ∖ {e}`。

**証明.** `z ≠ e` を取り、`w_n = z e^n z^{-1}` とおく。`mu(w_n) = e` なので `w_n ∈ T`。
`w_n` の空でない**真の**接頭辞は `z e^j` だけで像は `z`。もし `z ∉ mu(X)` なら、それらは
トークンではないので、`w_n` を覆う可能性は「`w_n` 自身が 1 トークン」だけ。`X` は有限
なので十分大きい `n` ではそれも不可能。∎

機械検証（スクリプト §4）: 20 元すべての `z` について `z e^n` の全接頭辞像が `z` で
あること、`z ≠ e` の 19 元について `z e^n z^{-1} ∈ T` かつ真の接頭辞像がすべて `z` で
あることを `n ≤ 21` で確認。さらに独立な経路として、実現可能なトークン像を
**グラフ判定**（下記 §3）で全数列挙し、20 個の極大真部分像すべてが実現不可能である
ことを確認した。

## 3. 判定基準（どのトークン像が実現可能か）

定理 1 は次の一般判定の特別な場合である。`A ⊆ G` に対し

    C_A = { w : w の空でないどの接頭辞も像が A に入らない }

とおく。有界遅延の符号で `mu(X) ⊆ A` を満たすものが存在する ⟺ `C_A` が有限。実際、
`C_A` が有限ならその**フロンティア** `X_A = { p g : p ∈ C_A, g ∈ Σ, mu(pg) ∈ A }` が
求める接頭符号になり、逆に `C_A` が無限なら任意の符号が無限に多くの語を覆えない。
そして `C_A` の有限性は**像の歩行のグラフ問題**に落ちる:

> `C_A` が無限 ⟺ 頂点集合 `G ∖ A`、辺 `v → v g`（`g ∈ Σ`、`v g ∉ A`）の有向グラフに、
> 1 文字の出発点から到達可能な閉路がある。

全要素アルファベットでは `e ∈ Σ` なので**すべての頂点に自己ループがある**。したがって
`G ∖ A ≠ ∅` なら常に閉路があり、`A = G` 以外は実現不可能 — これが定理 1 の別証である。

機械検証（スクリプト §3）: 3 つのアルファベット × 21 個の像でグラフ判定と
`C_A` の直接列挙が完全一致（0 不一致、`C_A` の列挙は `|G| + 1 = 21` で打ち切るが、
それは証明である。長さ 21 の `C_A`-語は像を 21 回訪れるので鳩の巣で像が重複し、
閉路が存在するため）。実現可能と判定された場合は毎回、実際にフロンティア符号を構成し、
接頭符号性・有界遅延・トークン像の包含を検査している。単調性（`A ⊆ A'` なら
`C_A ⊇ C_{A'}`）も 190 組で確認済みで、これにより「すべての真部分像」の検査を
「20 個の極大真部分像」に還元している。

## 4. 系: ルート (iii) は自分自身への還元である

`mu(X) ⊇ G ∖ {e}` なので、トークンアルファベットの像は `eps ∈ {0,1,2,3}` を
すべて含む。特に `eps = 2` の元（5 個のうち少なくとも 4 個）を含む。ところが
`F20-FULL-OBS-01` の period-2 障害は **`eps = 2` のトークン 1 個から生じる**。
したがってトークンレベルでも base cut は認証されない。機械検証:

| トークン像 | base cut | 291 候補パターン |
|---|---|---|
| `mu(X) = F_20`（20 文字） | 非周期でない、period 2、witness `g(e=2,b=0)` | 0 が認証 |
| 19 文字（`e` 消去後、下記 §5） | 非周期でない、period 2、同じ witness | — |

トークンの**重複度**も助けにならない。真のトークンアルファベット `Σ²`（400 トークン、
base cut の DFA は 1,606 状態）で、`eps = 2` のトークン 1 個の遷移が period 2 を
持つことを直接確認した。像が同じ相異なるトークンを別文字として区別しても、位相の
往復 `1 ↔ 3` は消えない。

**要点**: ブロック分解はアルファベットを `mu(X)` に取り替える操作にすぎず（§1）、
全要素アルファベットでは `mu(X)` が全体に戻る（§2）。したがってルート (iii) は
**問題を自分自身に還元する**。得るものはない。

## 5. 有限符号を諦める方向も塞がっている（挟み撃ち）

ルート (iii) が本当に欲しかったのは「**位相中立な**符号」である。全トークンが
`Σ eps ≡ 0 (mod 4)` なら、トークン境界の接尾位相はつねに 0 なので

    beta(w) = Σ_k beta~(x_k),   beta~(x) はトークン型だけで決まる定数

となり、`beta` が**トークン型の素朴なカウント**になる。これは決定的に強い。だが:

> **補題 2.** 位相中立な符号は（有限でも無限でも）有界遅延を持たない。

`u h^n`（`eps = 1` の文字のあと `eps = 2` の文字 `n` 個）の接頭辞の総位相は
`1, 3, 1, 3, ...` で、`0` に一度も到達しない（機械検証、`n ≤ 14`）。同様に
「総位相 2 を避けるトークンだけの符号」も `h e^n` で破れる（接頭辞の総位相はつねに 2）。

唯一の正準な位相中立符号は**最初の帰還語**の符号 `R`（位相歩行がちょうど末尾で 0 に
戻る語）である。`T = R*` が成り立ち、トークンは位相中立で、`beta` はカウントになる。
それでも二重に失敗する:

1. **`R` は無限**（機械検証: 長さ 3..15 の帰還語を明示的に構成）。よって §5.9 の鍵 1
   「有限にすれば星無し性は自明」は使えない。
2. **`R` は星無しでない**。`R` の DFA は §5.5 の base cut の DFA **そのもの**であり、
   `F20-FULL-OBS-01` によって period 2 の元 `g(e=2,b=0)` を持つ。

つまり有限符号は定理 1 で塞がれ、自然な無限符号は非周期性で塞がれる。この 2 つが
挟み撃ちになっているのが、ルート (iii) が閉じている構造的な理由である。

## 6. 副産物: 恒等文字は消してよい（新しい還元、`FULL-ALPH-RED-02`）

定理 1 の証明は恒等文字 `e` を本質的に使う。ならば `e` を先に消せばよいのでは、と
考えるのが自然である。実際それは**正当**であり、`FULL-ALPH-RED-01` を 1 文字だけ
鋭くする独立に有用な補題になる。

`pi : Σ* → (Σ ∖ {e})*` を `e` の消去とする。`mu = mu ∘ pi` なので
`T_Σ = pi^{-1}(T_{Σ∖{e}})`（機械検証: 長さ ≤ 3 の全 8,421 語）。

> **補題 4.** `pi^{-1}` は一般化スター高さ ≤ 1 を保つ。したがって
> `gsh(T_{Σ∖{e}}) ≤ 1 ⟹ gsh(T_Σ) ≤ 1`：**全要素アルファベットの還元は
> `|G| − 1` 文字で足りる。**

証明は 4 段:

1. `pi^{-1}` は Boolean 演算と可換。
2. `pi^{-1}(L_1 L_2) = pi^{-1}(L_1) pi^{-1}(L_2)`。消去は文字を融合も分割もしないので、
   `pi(w)` の分解が `w` の切り口に持ち上がる（機械検証: 9,837 事例）。
3. `L` が星無しなら `pi^{-1}(L)` も星無し。`pi` はモノイド射なので `pi^{-1}(L)` は
   `L` の構文モノイドで認識され、構文モノイドはそれを割るから非周期性が伝わる。
4. 星の段: `pi^{-1}(A*) = (B ∪ {e})*`、ここで `B = pi^{-1}(A)` から空語と
   **`e` で終わる語**を除いたもの。`A` が星無しなら `B ∪ {e}` も星無し（3 と
   「`e` で終わらない」の交叉）。

段 4 は注意を要する。**素朴な推測 `pi^{-1}(A*) = ({e} ∪ A)*` は誤りである**:
`A = {a, k a}`、`w = k e a` とすると `pi(w) = k a ∈ A` だが、`w` では `k` と `a` が
隣接していないので `w ∉ ({e} ∪ A)*`。正しい形は「各ブロックの最後の非 `e` 文字の
直後で切る」であり、それが `B` の定義の「`e` で終わらない」条件である。機械検証は
正しい等式が 4 つの試験符号 × 3,280 語すべてで成立し、素朴な等式が 3 つの符号で
実際に破れることの両方を確認している（判定器が空虚でないことの control）。

なお補題 4 は「非アルファベット的な逆射は高さを保たない」（PST 1992 項目 7、
`PROOF_OBLIGATIONS.md` N-F20-001 ルート (iv) に記録）と矛盾しない。あちらは一般の
射についての注意であり、こちらは消去射という特別な場合。破れるのは段 2 で、
文字をより長い語に写す射では `pi(w)` の分解が `w` の切り口に持ち上がらない。
**この補題は独立監査に回すべき項目として登録する**（`PROOF_OBLIGATIONS.md`）。

そして肝心の点: **消去は助けにならない**。19 文字アルファベットでもグラフ判定は

- サイズ 18 のトークン像は 190 通りすべて実現不可能
- サイズ 19 の像は 20 通りすべて実現可能

を返す。つまり `|mu(X)| ≥ 19` で、トークンアルファベットは依然 `eps = 2` の元を持ち、
base cut は period 2 で落ちる（機械検証済み）。

## 7. positive control（判定器が空虚でないこと）

「全部失敗した」は判定器のバグでも同じ出力になる。定理 1 が**アルファベット固有**で
あることを示す control を置いた。`F20-STD-01` の 2 生成元アルファベット `{a, b}` では:

| 制約 | 最小トークン像のサイズ | 符号 |
|---|---|---|
| なし | 2 / 20 | `X = {a, b}`（自明な符号） |
| 長さ 1 のトークン禁止 | 4 / 20 | `X = Σ²`、4 トークン、長さ 2 |

すなわち 2 生成元では**真部分像を持つ有界遅延の有限符号が実在する**（後者は長さ 2 の
ブロックだけからなる本物のブロック分解で、20 元中 4 元しか像に現れない）。全要素
アルファベットでは同じ探索がサイズ ≤ 3 の像を 1 つも返さず、最小は 20 である。
**差を作っているのは恒等文字**であり、判定器は「常に失敗」を返しているのではない。

## 7.5 残った抜け道 1 の決着: 探索ではなく 1 回の計算（`F20-BASECODE-01`）

「有限性は星無し性のための手段でしかない。星無しな**無限**符号ならどうか」——これを
最有望の残りとして登録したが、**問いの形が甘かった**。正しく見ると探索の余地がない。

`T = mu^{-1}(e)` は**両側 unitary** である: `uv ∈ T` かつ `u ∈ T` なら `v ∈ T`、逆側も
同様（機械検証: 長さ ≤ 4 の全語、ファイバー 8,422 語）。自由モノイドの両側 unitary な
部分モノイドは**自由**なので、`T` の生成基底は**一意**に決まる。その基底は

    R_T = { w ∈ T ∖ {ε} : w の真の空でない接頭辞は T に入らない }
        = 「最初に単位元へ戻る語」の集合

である（機械検証: 長さ ≤ 4 で `T ∖ (T∖{ε})²` と `R_T` が完全一致、7,240 語）。
したがって「`C* = T` なる星無し**符号** `C` は存在するか」は、候補が 1 つしかない
決定問題に還元される。答えは **NO**:

> `R_T` の最小 DFA は 22 状態で、その構文モノイドにおいて**単文字 `a = (x ↦ x+1)` が
> period 5** を持つ。よって非周期的でなく、シュッツェンベルジェにより星無しでない。

（初回は遷移モノイドを全列挙して確認した — 全 20 文字で 20,971,502 元、最大 period 5。
スクリプトに載せたのは同じ結論を `O(状態数)` で出す witness 版である。最小化を先に
行うのは必須で、非最小オートマトンの period は商で消えうる。）

**そして決定的なのは 2 生成元アルファベットでの同じ計算である。** あちらは
`F20-STD-01` で **`gsh(T) = 1` が既に証明済み**なのに、基底符号は同じく星無しでない
（22 状態、period 5、遷移モノイド 294,881 元）。「`C* = T` なる星無し `C`」は高さ 1 の
**十分条件にすぎず**、しかも**高さ 1 が成り立っている実例で既に破れている**。つまり
この抜け道は、閉塞したというより**初めから機構になりえなかった**。私が §8 で
「最有望」と評価したのは誤りだったので、ここで訂正する。

範囲について正直に言うと: `C` に**符号であること**を課さない一般形（`R_T ⊆ C ⊆ T` を
満たす任意の `C`）は、この計算では決着していない。データ点は 2 つ（`C = R_T` は上記、
`C = T` も構文モノイドが群 `F_20` なので星無しでない）。ただし上の calibration により、
一般形を追う動機自体が失われている。

## 8. 主張していないこと

- **`F_20` の全アルファベット版が高さ 2 であるとは主張しない。** 既知の 1 機構
  （有限符号ブロック分解）がこのインスタンスでは何も新しく与えない、という構造的
  事実にすぎない（README 研究ルール 1）。下界は一切含まない。
- 2 生成元版（`F20-STD-01`）は**影響を受けない**。§7 のとおり、あちらでは真部分像の
  符号が実在する。
- `F20-FULL-OBS-01`（`eps = 2` 局在、認証層）と `F20-SUB10-OBS-01`（同一 `eps` の
  2 文字の順序、表現力層）は**訂正されない**。本結果はそれらを前提として使う。
- `FRONTIER-ORD20-01` の `F_20` は**依然 open**。

**塞がっていない抜け道**（正直に記録する。定理 1 は「有限」かつ「有界遅延の貪欲
パース」を仮定している）:

1. ~~**星無しな無限符号**。有限性が欲しかったのは星無し性のためであって、必要なのは
   星無し性だけである。正準な候補 `R` は §5 で落ちたが、無限符号一般は排除できて
   いない。ここが最も有望な残りである。~~
   **決着した（下記 §7.5）。しかもこのルートは初めから成立しえなかった。**
2. **貪欲でないパース**（両側・文脈依存・非決定的な因数分解）。
3. **符号ごとに場合分けする有限和**。定理 1' は 1 つの符号について述べているが、
   ファイバーを有限個の場合に割り、場合ごとに別の符号を使う設計は排除していない
   （ただし `z e^n z^{-1}` の族はどの場合に入っても同じ問題を起こす）。
4. **`eps = 0` 文字を先に星無しな方法で剥がす**方向。§6 は `e` 1 文字については
   完全に解決したが、`beta ≠ 0` の非 mover 4 文字は消去できない（像を変える）。

## 9. 次の一手（`PROOF_OBLIGATIONS.md` N-F20-001 に反映）

- ルート (iii) は **BLOCKED**、抜け道 1 も §7.5 で決着（`F20-BASECODE-01`）。残るのは
  抜け道 2（貪欲でないパース）と 3（場合ごとに符号を変える有限和）だけで、どちらも
  「機構」と呼べる形にまだなっていない。ルート (iii) は実質的に閉じたと見る。
- **§7.5 の calibration は他ルートの評価基準として再利用すべきである。** 新しい機構を
  提案したら、まず 2 生成元アルファベット（`gsh = 1` が証明済み）に当てて**そこで
  成功するか**を見る。そこで失敗する機構は、全要素アルファベットで成功しえない。
  これは §5.13 の positive control を「判定器の非空虚性」から「機構の必要条件」へ
  格上げしたものである。
- ルート (iv)（アルファベット的逆射による閉性）と (v)（下界側）は未着手のまま。
  §6 の補題 4 はルート (iv) の周辺を 1 文字ぶん前進させたが、`|G|` から `|G| − 1` へ
  の還元であって機構の変更ではない。
- `FULL-ALPH-RED-02`（補題 4）は他の全要素アルファベット候補（`A_5`、`C_7⋊C_3`、
  `S_4`）にもそのまま効く。**再利用可能な還元として独立監査に回すべき**。
