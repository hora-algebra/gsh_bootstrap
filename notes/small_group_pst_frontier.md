# 小さい非可換有限群における「既知手法の被覆」の完全判定（2026-07-25）

対象は各有限群 `G` の **full solution**:

> 任意の有限アルファベット `Σ`、任意のモノイド射 `φ : Σ* → G`、任意の受理集合
> `P ⊆ G` に対し、`φ⁻¹(P)` の一般化スター高さは 1 以下である。

（`AGENTS.md` の `HeightOneForGroup G`。特定の生成元での word problem より真に強い。）

機械検証: `scripts/small_group_pst_coverage.py`（Python 標準ライブラリのみ、約 3 秒）。
実行マニフェスト: `data/experiments/small_group_pst_coverage.md`。

## 1. 使う既知定理（すべて台帳にある）

| ID | 主張 | ステータス |
|---|---|---|
| `PST-GRP-01` | `G` 可換 ⟹ full solution | `CITED`（PST 1992） |
| `PST-GRP-02` | `G` 冪零・class ≤ 2 ⟹ full solution | `CITED`（PST 1992, Thm 7.3） |
| `PST-GRP-03` | `G` が `A ⋊ E`（`A` 可換、`E` 基本可換 2 群）を**割る** ⟹ full solution | `CITED`（PST 1992） |

`PST-GRP-03` の「割る」（divides = 部分群の商）が本ノートの主役である。以下ではこの
クラスを **PST クラス** と呼ぶ。

## 2. 補題 1: PST クラスの決定可能な必要条件（`PST-DIV-CRIT-01`）

> **補題 1.** `G` が `A ⋊ E`（`A` 可換、`E` 基本可換 2 群）を割るならば、`G` は
> 可換正規部分群 `B ◁ G` を持ち、`G/B` は基本可換 2 群である。

**証明.** `G ≅ K/N`（`K ≤ A ⋊ E`, `N ◁ K`）と書く。`B₀ = K ∩ A` は可換で `K` の正規
部分群であり、`K/B₀` は `E` の部分群に単射に写るので基本可換 2 群である。
`B = B₀N/N` は `B₀` の商だから可換、`K/N` の正規部分群であり、
`(K/N)/B ≅ K/(B₀N)` は `K/B₀` の商なので基本可換 2 群。∎

この論法自体は新しくない — `RESULTS.md` §3 が `A₄` に対して同じ完全列を使っている。
本ノートの寄与は、これを**有限群 `G` について完全に判定可能な条件**として切り出した
点である。実際、条件は

- `G` のすべての可換正規部分群 `B` を列挙し、
- ある `B` で「全ての `x` に対し `x² ∈ B`」かつ「全ての `x,y` に対し `[x,y] ∈ B`」

が成り立つか、という有限チェックに等価である（`G/B` が基本可換 2 群 ⟺ この 2 条件）。

**重要**: 条件が破れれば、`A` と `E` の**大きさに関係なく** `G` は PST クラスに属さない
（これは探索結果ではなく証明である）。逆向きは必要条件にすぎないので、条件を満たす群
については実際の埋め込みを別に与える必要がある（補題 2 と §3 がそれを行う）。

## 3. 補題 2: 二面体群・双環群は一律に PST クラス（`DICM-EMB-01`）

`D_n = C_n ⋊ C₂` は定義から PST クラス（`A = C_n`, `E = C₂`）。問題は双環群
`Dic_n = ⟨x, y | x^{2n} = 1, y² = xⁿ, y⁻¹xy = x⁻¹⟩`（位数 `4n`）である。これは分裂
拡大ではないので `A ⋊ C₂` の形には書けない（`n = 2^k` の場合が一般四元数群
`Q_{2^{k+2}}`）。

> **補題 2.** 任意の `n ≥ 2` に対し `A = ⟨u⟩ × ⟨v⟩ ≅ C₂ × C_{2n}` と
> `φ(u) = u vⁿ`, `φ(v) = v⁻¹` で定まる `φ ∈ Aut(A)` を取り、`H_n = A ⋊ ⟨t⟩`
> （`t² = 1`, `t` は `φ` で作用）と置く。このとき
>
>     x ↦ v,    y ↦ u t
>
> は `Dic_n ↪ H_n` を与える。特に `Dic_n` は PST クラスに属し、full solution を持つ。

**証明.** `φ² = id` は直接計算（`φ²(u) = φ(u vⁿ) = u vⁿ v⁻ⁿ = u`）。`H_n` において

    (u t)² = u · φ(u) = u · u vⁿ = vⁿ,        (u t)⁻¹ v (u t) = φ(v) = v⁻¹

なので定義関係 `y² = xⁿ`, `y⁻¹xy = x⁻¹` が満たされる。`Dic_n` の任意の元は
`x^i` または `x^i y`（`0 ≤ i < 2n`）に一意に書けるので、像は `v^i` と `v^i u t` の
`4n` 個であり、`H_n`（位数 `8n`）の座標からすべて相異なる。よって単射。∎

`n = 2..12` について、この明示写像がそのまま準同型かつ単射であることを機械検証した
（`scripts/small_group_pst_coverage.py` の [5]）。これは `DIC3-RED-01`
（`Dic_3 ↪ (C_3×C_4)⋊C_2`, 2026-07-23）を全ての `n` に一般化し、副産物として
**すべての一般化四元数群** `Q_{2^k}` も PST クラスに入れる。

## 5. 帰結: 現在の frontier

`A_4` は本リポジトリで解決済み（`A4-ALLLANG-01`、`COMPUTED`、独立査読未了）。
したがって、既知手法と本リポジトリの成果を合わせた時点で残るのは

1. **位数 20: `F_20 = C_5 ⋊ C_4`（忠実）** ← 最小の未解決非可換群
2. 位数 21: `C_7 ⋊ C_3` ← 最小の**奇数位数**の未解決例。Bourne が破綻した
   `A ⋊ C_3` そのもの（`SMALL-C3-FAIL`）
3. 位数 24: `SL(2,3)`, `S_4`, `C_2 × A_4`

`S_4` は `RESULTS.md` §6 の候補リスト項目 3 で既に名指しされていたが、本判定は
それを**完全なリスト**に格上げする。`A_4` を解いた counting 構成は
「可換正規部分群 ⋊ 巡回商」に依存しており、`F_20`（商が `C_4`、忠実作用）と
`C_7⋊C_3`（商が `C_3`）はその外にある。

`S_4` は 2026-07-25 の `WEIS-L2-GSH-01`（フル版 L2、構文モノイド `C₂×S_4`）とも
直結する: あの結果は `C₂×S_4` が認識する**ある 1 つの言語**を落としただけで、
`HeightOneForGroup (C₂×S₄)` は未解決のままである。

## 6. 主張していないこと（射程の限界）

- **「PST クラス外」は下界ではない。** 高さ ≥ 2 を意味しない。既知の被覆機構が
  当てはまらない、という構造的事実だけである（README 研究ルール 1）。
- **文献の網羅性は保証していない。** 判定は台帳にある `PST-GRP-01/02/03` に対して
  行った。特に PST 1992 の**ラッパー積・pseudovariety 系の結果**
  （`docs/SURVEY.md` §3 項目 6）は本リポジトリで一次資料監査していないので、
  そこから `F_20` などが落ちる可能性を排除できない。1992–2026 の文献で
  これら 6 群が個別に扱われていないことも確認していない。
  したがって「位数 20 が最小の未解決」は**本リポジトリの監査範囲での主張**である。
- **群の分類そのものは引用**である（各位数の群の個数）。本スクリプトは構成した
  リストが互いに非同型でその個数に一致することを検証するだけで、分類定理を
  証明していない。
- 位数 32 以上は判定していない（位数 32 には非可換群が 44 個ある）。
