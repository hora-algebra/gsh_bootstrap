# 小さい非可換有限群における「既知手法の被覆」の完全判定（2026-07-25）

対象は各有限群 `G` の **full solution**:

> 任意の有限アルファベット `Σ`、任意のモノイド射 `φ : Σ* → G`、任意の受理集合
> `P ⊆ G` に対し、`φ⁻¹(P)` の generalized star-height は 1 以下である。

（`AGENTS.md` の `HeightOneForGroup G`。特定の生成元での word problem より真に強い。）

機械検証: `scripts/research/small_group_pst_coverage.py`（Python 標準ライブラリのみ、約 3 秒）。
実行マニフェスト: `data/experiments/small_group_pst_coverage.md`。

## 1. 使う既知定理（すべて台帳にある）

| ID | 主張 | ステータス |
|---|---|---|
| `PST-GRP-01` | `G` 可換 ⟹ full solution | `CITED`（PST 1992） |
| `PST-GRP-02` | `G` 冪零・class ≤ 2 ⟹ full solution | `CITED`（PST 1992, Thm 7.3） |
| `PST-GRP-03` | `G` が `A ⋊ E`（`A` 可換、`E` 基本可換 2 群）を**割る** ⟹ full solution | `CITED`（PST 1992） |

`PST-GRP-03` の「割る」（divides = 部分群の商）が本ノートの主役である。以下ではこの
クラスを **PST クラス** と呼ぶ。

## 2. 補題 1: PST クラスの決定可能な必要条件（`PST-DIV-CRIT-01`）

> **補題 1.** `G` が `A ⋊ E`（`A` 可換、`E` 基本可換 2 群）を割るならば、`G` は
> 可換正規部分群 `B ◁ G` を持ち、`G/B` は基本可換 2 群である。

**証明.** `G ≅ K/N`（`K ≤ A ⋊ E`, `N ◁ K`）と書く。`B₀ = K ∩ A` は可換で `K` の正規
部分群であり、`K/B₀` は `E` の部分群に単射に写るので基本可換 2 群である。
`B = B₀N/N` は `B₀` の商だから可換、`K/N` の正規部分群であり、
`(K/N)/B ≅ K/(B₀N)` は `K/B₀` の商なので基本可換 2 群。∎

この論法自体は新しくない — `RESULTS.md` §3 が `A₄` に対して同じ完全列を使っている。
本ノートの寄与は、これを**有限群 `G` について完全に判定可能な条件**として切り出した
点である。実際、条件は

- `G` のすべての可換正規部分群 `B` を列挙し、
- ある `B` で「全ての `x` に対し `x² ∈ B`」かつ「全ての `x,y` に対し `[x,y] ∈ B`」

が成り立つか、という有限チェックに等価である（`G/B` が基本可換 2 群 ⟺ この 2 条件）。

**重要**: 条件が破れれば、`A` と `E` の**大きさに関係なく** `G` は PST クラスに属さない
（これは探索結果ではなく証明である）。逆向きは必要条件にすぎないので、条件を満たす群
については実際の埋め込みを別に与える必要がある（補題 2 と §3 がそれを行う）。

## 3. 補題 2: 二面体群・双環群は一律に PST クラス（`DICM-EMB-01`）

`D_n = C_n ⋊ C₂` は定義から PST クラス（`A = C_n`, `E = C₂`）。問題は双環群
`Dic_n = ⟨x, y | x^{2n} = 1, y² = xⁿ, y⁻¹xy = x⁻¹⟩`（位数 `4n`）である。これは分裂
拡大ではないので `A ⋊ C₂` の形には書けない（`n = 2^k` の場合が一般四元数群
`Q_{2^{k+2}}`）。

> **補題 2.** 任意の `n ≥ 2` に対し `A = ⟨u⟩ × ⟨v⟩ ≅ C₂ × C_{2n}` と
> `φ(u) = u vⁿ`, `φ(v) = v⁻¹` で定まる `φ ∈ Aut(A)` を取り、`H_n = A ⋊ ⟨t⟩`
> （`t² = 1`, `t` は `φ` で作用）と置く。このとき
>
>     x ↦ v,    y ↦ u t
>
> は `Dic_n ↪ H_n` を与える。特に `Dic_n` は PST クラスに属し、full solution を持つ。

**証明.** `φ² = id` は直接計算（`φ²(u) = φ(u vⁿ) = u vⁿ v⁻ⁿ = u`）。`H_n` において

    (u t)² = u · φ(u) = u · u vⁿ = vⁿ,        (u t)⁻¹ v (u t) = φ(v) = v⁻¹

なので定義関係 `y² = xⁿ`, `y⁻¹xy = x⁻¹` が満たされる。`Dic_n` の任意の元は
`x^i` または `x^i y`（`0 ≤ i < 2n`）に一意に書けるので、像は `v^i` と `v^i u t` の
`4n` 個であり、`H_n`（位数 `8n`）の座標からすべて相異なる。よって単射。∎

`n = 2..12` について、この明示写像がそのまま準同型かつ単射であることを機械検証した
（`scripts/research/small_group_pst_coverage.py` の [5]）。これは `DIC3-RED-01`
（`Dic_3 ↪ (C_3×C_4)⋊C_2`, 2026-07-23）を全ての `n` に一般化し、副産物として
**すべての一般化四元数群** `Q_{2^k}` も PST クラスに入れる。

## 3.5 補題 3: PST のラッパー積定理は非可換群を 1 つも覆わない（`PST-WREATH-COMM-01`）

`docs/SURVEY.md` §3 項目 6 の「ラッパー積・pseudovariety 系の結果」は、本ノート初版で
**未監査の caveat** として残していた。PST 1992 の abstract によればその主張は

> 有理言語 `L` が、`M ∘ (G ∘ N)`（`M`, `N` は aperiodic モノイド、`G` は可換群）
> の形のラッパー積が生成する variety のモノイドに認識されるなら、`L` の
> star-height は ≤ 1 である。

という形をしている（2026-07-25 に web 検索経由で abstract のこの文を取得。
**2026-07-28 に一次資料で verbatim 確認済み**: PST 1992 Theorem 7.8、
`https://www.irif.fr/~jep/PDF/StarHeight.pdf` p. 27。ただし正確な形は
`A ∗ Gcom ∗ A` すなわち `G ◦ M` で `G` 可換・`M` **aperiodic** であり、
abstract 由来の `M ∘ (G ∘ N)` はどちらの因子が aperiodic かを言っていない。
下の補題 3 はどちらの convention でも成り立つように証明してある）。
重要なのは**群の層が `G` の 1 枚だけ**という形であり、これだけで次が言える。

> **補題 3.** `V` を、`M ∘ (G ∘ N)`（`M`, `N` は有限 aperiodic モノイド、`G` は
> 有限可換群）が生成するモノイド pseudovariety とする。このとき `V` に属する群は
> すべて可換である。

**証明.** (a) 有限モノイドについて「群 `H` がモノイド `W` を割る ⟺ `H` は `W` の
ある部分群を割る」（標準的な半群論の事実。`W` を割る群は `W` の極大部分群を割る群と
一致する）。

(b) `M` が aperiodic なら、ラッパー積 `M ∘ P = M^P ⋊ P` の任意の部分群は `P` の
部分群に埋め込まれる。実際、射影 `π : M ∘ P → P` はモノイド射であり、部分群 `H` に
対し `π(H)` は `P` の部分群、`ker(π|_H)` は `M^P` の部分群である。`M^P` は aperiodic
モノイドの有限直積冪なので aperiodic、よってその部分群は自明。ゆえに `H ≅ π(H) ≤ P`。

(c) `N` が aperiodic なら、同じ射影論法で `G ∘ N` の部分群は `G^N` に埋め込まれる
（`N` への像は `N` の部分群だから自明）。`G` が可換なら `G^N` も可換。

(d) (b) を `P = G ∘ N` に適用し (c) と合わせると、`M ∘ (G ∘ N)` の部分群は可換。
`V` の群は有限個のそうしたラッパー積の積を割り、積の部分群は部分群の積なので可換、
(a) より可換群の商、したがって可換。∎

ラッパー積の左右の規約（`M ∘ P` を `M^P ⋊ P` と取るか `P^M ⋊ M` と取るか）を
入れ替えても、aperiodic 側への射影の像が自明になるという論法は同じなので**結論は
変わらない**。これは規約を一次資料で確認できていない現状で重要な頑健性である。

**帰結**: 項目 6 は非可換群の full solution を 1 つも与えない。よって §4 の 6 つの
例外に対する「未監査の被覆定理があるかもしれない」という留保のうち、**PST 1992 内部の
分については解消した**。残る留保は 1992–2026 の他文献である（§6）。

## 6. 主張していないこと（射程の限界）

- **「PST クラス外」は下界ではない。** 高さ ≥ 2 を意味しない。既知の被覆機構が
  当てはまらない、という構造的事実だけである（README 研究ルール 1）。
- **文献の網羅性は保証していない。** 判定は台帳にある `PST-GRP-01/02/03` に対して
  行った。PST 1992 の**ラッパー積・pseudovariety 系の結果**（`docs/SURVEY.md` §3
  項目 6）については、2026-07-25 に §3.5 の補題 3 で「非可換群を 1 つも覆わない」ことを
  証明したので、**PST 1992 内部の留保は解消した**。補題 3 が前提とする定理は
  **2026-07-28 に一次資料で verbatim 確認済み**（Theorem 7.8、`irif.fr` の PDF
  p. 27）。ただし 1992–2026 の他文献でこれら 6 群が個別に扱われていないことは
  確認していない。
  したがって「位数 20 が最小の未解決」は依然**本リポジトリの監査範囲での主張**である。
- **群の分類そのものは引用**である（各位数の群の個数）。本スクリプトは構成した
  リストが互いに非同型でその個数に一致することを検証するだけで、分類定理を
  証明していない。
- 位数 32 以上は判定していない（位数 32 には非可換群が 44 個ある）。
